# ReviewIQ AI - Frontend

ReviewIQ AI is an AI-powered Customer Review Intelligence Platform that helps businesses analyze customer reviews and gain actionable insights.

## 🚀 Features

- Dashboard
- Upload Reviews
- Aspect Analysis
- Branch Performance
- Trend Analysis
- AI Recommendations
- User Profile
- Settings

## 🛠️ Built With

- React
- TypeScript
- Vite
- Material UI
- React Router
- Recharts

## 📦 Run Locally

```bash
npm install
npm run dev
```
